# Princi v0.2.0

Princi 0.2.0 is the Windows x86-64 release of the v0.2 language and compiler.
It preserves the v0.1 build workflow and `.prnc` / `.princi` source
equivalence, and adds monomorphized generics, bounds, interfaces, traits,
algebraic enums, pattern matching, `Result<T, E>`, and postfix `?` propagation.

## Build command

```powershell
princi build hello.prnc
princi build hello.princi
princi build hello.prnc -o app.exe
```

Both source extensions are aliases. The first two commands produce
`hello.exe`; `-o` selects another executable path.

## Language additions

- Generic functions, classes, structs, and enums with nested types, bounded
  parameters, local inference where unambiguous, and deterministic
  monomorphization.
- Class interface values with runtime dispatch. Traits support abstract and
  default methods, class and struct implementations, and trait values.
- Enum variants with payloads, match patterns and expressions, wildcard arms,
  and exhaustiveness diagnostics.
- The embedded generic `Result<T, E>` enum and `?` propagation when error types
  match exactly.

The full boundaries and limitations are in [`docs/v0.2-scope.md`](../v0.2-scope.md).
Compiler and native integration coverage is documented in the
[v0.2 testing matrix](../v0.2-testing-matrix.md).

## Requirements

The compiler installer does not bundle native build tools. Compiling Princi
programs still requires LLVM/Clang 15+ with LLVM IR and X86 support and
x86-64 MinGW-w64 GCC targeting `x86_64-w64-mingw32`. Both must be available on
`PATH`, or selected with `PRINCI_CLANG` and `PRINCI_CC`. See the root README's
[Windows setup](../../README.md#windows-setup).
