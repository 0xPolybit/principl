# Princi v0.1.0

Princi v0.1.0 is the first packaged Windows x86-64 release of the Princi
compiler. The installer places the `princi` command in the current user's
programs directory and can add it to the user's `PATH`. It can also add a
**Build with Princi** Explorer action for `.prnc` and `.princi` files without
changing the default application used to edit them.

## Requirements

The installer contains the Princi compiler, but does not bundle LLVM or
MinGW-w64. Compiling Princi programs requires:

- LLVM/Clang 15 or newer with LLVM IR input and the X86 target.
- x86-64 MinGW-w64 GCC targeting `x86_64-w64-mingw32`.

Both tools must be available on `PATH`, or configured with `PRINCI_CLANG` and
`PRINCI_CC`. See the repository README's [Windows setup guide](../../README.md#windows-setup).

## Install

Download and run `Princi-Setup-0.1.0-x64.exe`. Open a new terminal after
installation, then build either source extension:

```powershell
princi build hello.prnc
princi build hello.princi
princi build hello.prnc -o app.exe
```

The `.prnc` and `.princi` extensions are interchangeable. Both default builds
create an executable next to the source file. Windows may show a SmartScreen
warning for this new, unsigned release.
