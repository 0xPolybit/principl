# Princi v0.2 conformance testing matrix

The v0.2 suite uses focused tests at each compiler boundary and native tests
for behavior that must survive the complete build. The matrix records where a
feature needs coverage and where that coverage currently lives.

| --- | --- | --- | --- | --- | --- |

`n/a after semantic rejection` is intentional: invalid programs must stop
before IR generation. The diagnostic and negative-build tests verify that
these cases fail without creating an executable. Native tests are Windows-only
because Princi v0.2 currently targets Windows x86-64.

## Coverage locations

- **Parser / AST:** unit tests in `src/parser.rs` cover generic declarations
  and nested type syntax, bounds, interfaces, traits, enum declarations,
  patterns, match arms, and postfix `?` precedence. `.prnc` / `.princi` pairs
  are checked for matching parsed forms.
- **Semantic:** unit tests in `src/semantic.rs` cover inference, arity, bounds,
  conformance, enum payloads, match exhaustiveness and reachability, result
  propagation, and invalid combinations.
- **Diagnostics:** `tests/cli.rs` checks stable v0.2 codes, source locations,
  useful notes, and suppression of redundant cascades. The v0.2 fixtures under
  `tests/fixtures/invalid/` additionally ensure invalid builds do not emit an
  executable.
- **LLVM / backend:** unit tests in `src/codegen/llvm.rs` inspect specialization
  reuse and names, recursion handling, concrete generic layouts, dispatch,
  enum tags and payloads, match lowering, and `?` branches.
- **Native executable:** Windows tests in `tests/native.rs` exercise individual
  features and interactions. `tests/conformance.rs` builds the paired v0.2
  fixture through both extensions, checks executable creation, launches each
  executable, and compares stdout, stderr, and exit code with fixtures.

## Running the suite

Run unit, CLI, fixture, and available Windows native tests in both profiles:

```powershell
cargo test
cargo test --release
```

Native tests require LLVM/Clang with X86 support and x86-64 MinGW-w64 GCC. Set
`PRINCI_REQUIRE_NATIVE_TESTS=1` on Windows to fail instead of skip when either
tool is unavailable.
