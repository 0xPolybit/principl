# PrinciPL website design direction

The user chose an editorial language-studio direction for developers
evaluating and trying Princi. Keep product facts sourced from the compiler
repository and lead visitors from a real source example to the local build
guide.

## Visual system

- Warm paper, near-black ink, and a measured vermilion accent.
- A high-contrast literary serif for display titles, a readable sans for
  interface and body copy, and monospace only for source, commands, and data.
- Generous reading measure with a compact compiler-notebook rhythm for code
  and pipeline details.
- Use rules, annotations, and typography to organize content. Avoid generic
  icon-card grids, fake terminal chrome, and decorative gradients.
- Pages remain light, responsive, keyboard accessible, and useful with motion
  reduced.

## Interaction

Navigation and copy-to-clipboard controls are the only client-side
interactions. The rest of the site renders as Server Components.
