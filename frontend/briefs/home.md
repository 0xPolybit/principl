# Homepage brief

**Mode:** Persuade

**Reader:** Developers evaluating and trying Princi.

**Question:** What is Princi today, what does its v0.1 compiler actually
support, and how can I build a first program on Windows?

**Success:** Within the first screen, a visitor can identify Princi as a
statically typed compiled language, see the exact Windows x86-64 boundary, and
open the build guide or language guide. The example uses syntax already
accepted by the repository.

**Pinned constraints:** Keep the implementation inside `/frontend`; preserve
the Rust compiler; keep `.prnc` and `.princi` explicitly equivalent; present
roadmap items as deferred, with no invented dates or promises.

**Direction:** An editorial language studio: a composed reading surface whose
first proof is a real Princi program and its one-command native build.

**Signature interaction:** Copy the displayed source or build command from an
accessible code sample.
